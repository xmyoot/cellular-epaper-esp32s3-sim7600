# NOT RELEASED — historical manufacturing exports

These Gerbers, drill files and placement data came from the original board and retain its electrical defects. **Do not fabricate or assemble from this directory.**

`BOM.csv` has been replaced with a schematic-derived, unqualified component list to remove the former footprint-as-value errors. It does not qualify the old Gerbers or placement file.

After the electrical redesign, regenerate all outputs together from the reviewed source and record the exact source commit. Required checks and blocking defects are documented in [review/README.md](../review/README.md).
